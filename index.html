Windows 10/11 64-bit Tanpa install
  1. 01

    Download ZIP

    Klik tombol download di halaman ini. Simpan di folder biasa—hindari Program Files biar nggak kena masalah izin.

  2. 02

    Extract semuanya

    Extract seluruh isi ZIP, bukan cuma exe-nya. Exe dan semua file pendukung harus tetap satu folder.

  3. 03

    Jalankan launcher

    Buka Flu Launcher.exe. Kalau SmartScreen muncul: More info → Run anyway. Exe-nya belum disertifikasi, bukan virus.

  4. 04

    Pilih versi & main

    Buka tab Versi, pilih versi Minecraft, klik Instal. Pilih loader kalau perlu. Setelah selesai, klik Main—offline-ready.

// FAQ

Masih mikir?

Jawaban singkat buat pertanyaan yang paling sering muncul.

Perlu install Java?

Nggak. Java 21 sudah dibawa di dalam folder launcher. Launcher juga bisa mendeteksi dan memakai Java lain kalau kamu mau.

Butuh internet?

Cuma saat instal versi atau loader pertama. Setelah file game tersimpan, kamu bisa main offline.

Kenapa antivirus nge-flag?

Exe belum punya sertifikat digital berbayar, jadi beberapa antivirus salah mendeteksi (false positive). File-nya nggak mengirim data ke mana-mana; semua tersimpan di folder data.

Bisa main LAN?

Bisa. Pastikan satu WiFi, versi Minecraft sama, dan mods sama. Buka dunia → Open to LAN, lalu temanmu join lewat Multiplayer.

Loader apa aja?

Vanilla, Fabric, OptiFine, Forge, dan NeoForge. Semua dipilih dari dialog Instal di tab Versi.

Save dan mods disimpan di mana?

Di folder data\game sebelah exe. Saves ada di saves, mods dipisah per profil di mods_store.
